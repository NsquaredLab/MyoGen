.. _basic-examples:

==================
Basic Tutorials
==================

This gallery contains fundamental MyoGen tutorials demonstrating core functionality and workflow patterns.

These examples cover the essential building blocks of neuromuscular simulation, from motor unit recruitment to EMG signal generation.

Overview
--------

The tutorials are organized to follow the natural simulation pipeline:

1. **Neural Control** - Motor unit recruitment and spike train generation
2. **Muscle Modeling** - Anatomical structure and force generation
3. **Signal Generation** - Surface and intramuscular EMG
4. **Utilities** - Helper functions for current generation and visualization

Recommended Learning Path
-------------------------

**Getting Started (30-60 minutes):**

1. Start with recruitment thresholds (``00_*``)
2. Generate spike trains from neural drive (``01_*``)
3. Create muscle model (``02_*``)
4. Generate EMG signals (``03_*``, ``04_*``)

**Advanced Topics:**

- Force generation (``06_*``)
- Intramuscular EMG (``08_*``)
- Spinal network simulation (``09_*``)

All examples are self-contained and can be run independently, though following the numbered order provides the best learning experience.
