# Neo Block Structure Diagrams

Visual representation of the hierarchical structure of each Neo Block type used in MyoGen.

================================================================================
1. SPIKE_TRAIN__Block
================================================================================

Block (name="Spike Trains")
│
├── Segment[0] (name="Pool_0")
│   ├── SpikeTrain[0] (name="MN_0")  → [spike_time_1, spike_time_2, ...]
│   ├── SpikeTrain[1] (name="MN_1")  → [spike_time_1, spike_time_2, ...]
│   └── SpikeTrain[n] (name="MN_n")  → [spike_time_1, spike_time_2, ...]
│
├── Segment[1] (name="Pool_1")
│   └── SpikeTrain[...] → ...
│
└── Segment[m] (name="Pool_m")
    └── SpikeTrain[...] → ...

Access Pattern:
    spike_train = block.segments[pool_idx].spiketrains[neuron_idx]
    spike_times = spike_train.magnitude  # 1D array

Data Type: Array of time stamps (seconds)
Example: array([0.123, 0.234, 0.345, ...])


================================================================================
2. SURFACE_MUAP__Block
================================================================================

Block (name="Surface MUAPs")
│
├── Group[0] (name="ElectrodeArray_0")
│   │
│   ├── Segment[0] (name="MUAP_0")
│   │   └── AnalogSignal[0] → 3D array (time × rows × cols)
│   │                          Shape: (500, 13, 5)
│   │
│   ├── Segment[1] (name="MUAP_1")
│   │   └── AnalogSignal[0] → 3D array (time × rows × cols)
│   │
│   └── Segment[n] (name="MUAP_n")
│       └── AnalogSignal[0] → 3D array (time × rows × cols)
│
├── Group[1] (name="ElectrodeArray_1")
│   └── Segment[...] → ...
│
└── Group[m] (name="ElectrodeArray_m")
    └── Segment[...] → ...

Access Pattern:
    muap = block.groups[array_idx].segments[muap_idx].analogsignals[0]
    electrode_signal = muap[:, row, col]  # Extract specific electrode

Data Type: 3D grid of voltages (mV or µV)
Shape: (time_samples, electrode_rows, electrode_columns)

Visual representation of one MUAP signal:

    Time axis ↓

    t=0   [ [e₀₀, e₀₁, e₀₂, ...],   ← Row 0 of electrodes
            [e₁₀, e₁₁, e₁₂, ...],   ← Row 1
            [e₂₀, e₂₁, e₂₂, ...] ]  ← Row 2
    t=1   [ [...], [...], [...] ]
    t=2   [ [...], [...], [...] ]
    ...


================================================================================
3. SURFACE_EMG__Block
================================================================================

Block (name="Surface EMG")
│
├── Group[0] (name="ElectrodeArray_0")
│   │
│   ├── Segment[0] (name="Pool_0")
│   │   └── AnalogSignal[0] → 3D array (time × rows × cols)
│   │                          Shape: (150000, 13, 5)
│   │
│   ├── Segment[1] (name="Pool_1")
│   │   └── AnalogSignal[0] → 3D array (time × rows × cols)
│   │
│   └── Segment[m] (name="Pool_m")
│       └── AnalogSignal[0] → 3D array (time × rows × cols)
│
└── Group[n] (name="ElectrodeArray_n")
    └── Segment[...] → ...

Access Pattern:
    emg = block.groups[array_idx].segments[pool_idx].analogsignals[0]
    electrode_signal = emg[:, row, col]  # Extract specific electrode

Data Type: 3D grid of voltages over time (mV or µV)
Shape: (time_samples, electrode_rows, electrode_columns)

Note: Similar structure to SURFACE_MUAP__Block, but:
    - MUAPs are templates (short duration)
    - EMG is the full signal (longer duration)
    - EMG = convolution of MUAPs with spike trains


================================================================================
4. INTRAMUSCULAR_MUAP__Block
================================================================================

Block (name="Intramuscular MUAPs")
│
├── Segment[0] (name="MUAP_0")
│   └── AnalogSignal[0] → 2D array (time × electrodes)
│                          Shape: (500, 4)
│
├── Segment[1] (name="MUAP_1")
│   └── AnalogSignal[0] → 2D array (time × electrodes)
│
└── Segment[n] (name="MUAP_n")
    └── AnalogSignal[0] → 2D array (time × electrodes)

Access Pattern:
    muap = block.segments[muap_idx].analogsignals[0]
    electrode_signal = muap[:, electrode_idx]  # Extract specific electrode

Data Type: 2D matrix of voltages (mV or µV)
Shape: (time_samples, n_electrodes)

Visual representation:

    Time ↓    Electrode 0  Electrode 1  Electrode 2  Electrode 3
    t=0         -0.12        -0.08        0.05         0.15
    t=1         -0.15        -0.11        0.08         0.18
    t=2         -0.18        -0.14        0.11         0.21
    ...         ...          ...          ...          ...


================================================================================
5. INTRAMUSCULAR_EMG__Block
================================================================================

Block (name="Intramuscular EMG")
│
├── Segment[0] (name="Pool_0")
│   └── AnalogSignal[0] → 2D array (time × electrodes)
│                          Shape: (150000, 4)
│
├── Segment[1] (name="Pool_1")
│   └── AnalogSignal[0] → 2D array (time × electrodes)
│
└── Segment[m] (name="Pool_m")
    └── AnalogSignal[0] → 2D array (time × electrodes)

Access Pattern:
    emg = block.segments[pool_idx].analogsignals[0]
    electrode_signal = emg[:, electrode_idx]  # Extract specific electrode

Data Type: 2D matrix of voltages over time (mV or µV)
Shape: (time_samples, n_electrodes)

Note: Similar structure to INTRAMUSCULAR_MUAP__Block, but:
    - MUAPs are templates (short duration)
    - EMG is the full signal (longer duration)


================================================================================
COMPARISON SUMMARY
================================================================================

Type                        Hierarchy Level          Dimensions  Shape
────────────────────────────────────────────────────────────────────────────
SPIKE_TRAIN__Block         Segments → SpikeTrain    1D          (n_spikes,)

SURFACE_MUAP__Block        Groups → Segments →      3D          (time, rows, cols)
                           AnalogSignal

SURFACE_EMG__Block         Groups → Segments →      3D          (time, rows, cols)
                           AnalogSignal

INTRAMUSCULAR_MUAP__Block  Segments →               2D          (time, electrodes)
                           AnalogSignal

INTRAMUSCULAR_EMG__Block   Segments →               2D          (time, electrodes)
                           AnalogSignal


================================================================================
KEY DIFFERENCES
================================================================================

SURFACE vs INTRAMUSCULAR:
    - Surface: 3D grid of electrodes (rows × columns)
    - Intramuscular: 1D linear array of electrodes

MUAP vs EMG:
    - MUAP: Templates/patterns of individual motor units (short duration)
    - EMG: Full signal from spike train convolution (long duration)

GROUPS:
    - Only surface recordings have Groups (multiple electrode arrays)
    - Intramuscular recordings don't have Groups (single array)

SEGMENTS:
    - MUAP blocks: Segments = individual motor units (MUAP_0, MUAP_1, ...)
    - EMG blocks: Segments = motor pools (Pool_0, Pool_1, ...)
    - Spike train blocks: Segments = motor pools


================================================================================
DATA FLOW
================================================================================

1. Generate Spike Trains
   ↓
   SPIKE_TRAIN__Block
   └─→ Segments (motor pools) → SpikeTrain (individual neurons)

2. Generate MUAPs
   ↓
   SURFACE_MUAP__Block or INTRAMUSCULAR_MUAP__Block
   └─→ Templates for each motor unit

3. Convolve MUAPs with Spike Trains
   ↓
   SURFACE_EMG__Block or INTRAMUSCULAR_EMG__Block
   └─→ Synthesized EMG signals

Workflow:
    Spike Trains + MUAPs → EMG Signals
    (when to fire)  (what it looks like)  (final signal)


================================================================================
MEMORY CONSIDERATIONS
================================================================================

Typical sizes (for reference):

SPIKE_TRAIN__Block:
    - Small: ~KB per neuron
    - Only stores spike times, not waveforms

SURFACE_MUAP__Block:
    - Medium: ~MB per motor unit
    - 500 samples × 13 rows × 5 cols × 100 MUs = ~26M floats = ~200 MB

SURFACE_EMG__Block:
    - Large: ~GB per simulation
    - 150k samples × 13 rows × 5 cols = ~10M floats = ~80 MB per pool

INTRAMUSCULAR_MUAP__Block:
    - Small: ~KB per motor unit
    - 500 samples × 4 electrodes × 100 MUs = ~200k floats = ~1.6 MB

INTRAMUSCULAR_EMG__Block:
    - Medium: ~MB per simulation
    - 150k samples × 4 electrodes = ~600k floats = ~4.8 MB per pool
