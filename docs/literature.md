# Literature register

Sources behind MyoGen's surface-EMG defaults, the fibre-dispersion options and the FDI descending-drive calibration (work of 2026-10-30 to 2026-11-01). Each parameter links to its sources; each source links to the code, tests and notes that use it. Every parameter needs a literature basis or must be labelled a modelling assumption.

To add a source: add a row in its topic table with an `id` anchor, link it from the parameter index, and cite the key in the code docstring.

**Status:** FT full text · FIG read off a figure · ABS abstract only · SEC known only through a citing paper · CODE source code · LINK named only  
**Use:** ADOPTED sets a default or code value (or is its stated basis) · CONTEXT comparator, bound or background · REJECTED considered and not used

## Corrections and open verification

1. **Skin σ = 1 S/m rationale.** First explained as gel electrodes bypassing the stratum corneum (Farina 2004). Unsourced and withdrawn: the value is Roeleveld et al. 1997's fitted effective skin, inherited by Blok 2002, Farina & Rainoldi 1999, Farina & Merletti 2001 and Farina 2004. Commit message reworded; nexus Part A step 3 still has the old wording.
2. **Roeleveld 1997 DOI** is 10.1016/S1050-6411(97)00009-6 (an earlier (96)00034-8 was wrong).
3. **'Konstantin et al. 2020'** in MyoGen docstrings (muscle.py, intramuscular_emg.py, nerve_branches.py) is Akhmadeev et al. 2020. Fixed on `fix/semg-amplitude-scale` (028a14362); the `konstantin` threshold mode keeps its name.
4. **Botelho 2019 simulated amplitude**: median ~0.16 mV; 0.10 mV was one sample trace. Their 24.8–40.6 µm diameters are Hwang 2013's FDI mean ± SD.
5. **Feinstein 1955** authors are Feinstein, Lindegård, Nyman, Wohlfart; ~40,000 fibres (not 40,500).
6. **Piasecki 2020 and Stålberg & Karlsson 2001** are one citation chain, not two anchors.
7. **Jacobson 1992's 2.8 mm** is probably between-specimen spread; MyoGen uses it as a uniform half-width (docstring corrected).
8. **Unverified, quoted from memory:** Moritz 2005 (ISI CV), Kukulka & Clamann 1981. **Never read in full:** Nandedkar & Stålberg 1983 (adopted CV line), Jacobson 1992 Table 1, Heckman & Binder 1991.
9. **McManus 2019 'MUAP amplitude'**: metric undefined, not usable as a target.
10. **ISI CV target 15–22 %** in the optimiser cites 'LIT-17' (iEMG nexus literature note); its primary source was not re-checked in these sessions.
