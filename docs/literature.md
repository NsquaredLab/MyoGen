# Literature register

Sources behind MyoGen's surface-EMG defaults, the fibre-dispersion options and the FDI descending-drive calibration (work of 2026-10-30 to 2026-11-02). Each parameter links to its sources; each source links to the code, tests and notes that use it. Every parameter needs a literature basis or must be labelled a modelling assumption.

**Citing in code:** a sourced value carries an inline comment with the key and a locator, e.g. `HIGH_FORCE_RATE_TARGETS = {40: 25.3, 80: 41.4}  # [deluca1982 p. 118 Table 1]`. Give only locators you have read; write "no locator" otherwise. Each key below resolves to the full citation and DOI.

To add a source: add it to the table in `scripts/build_literature.py`, link it from the parameter index, cite the key in the code, and rerun the script (`--check` fails on unknown keys or a stale file). "Cited at" lists are generated from the code.

**Status:** FT full text · FIG read off a figure · ABS abstract only · SEC known only through a citing paper · CODE source code · LINK named only  
**Use:** ADOPTED sets a default or code value (or is its stated basis) · CONTEXT comparator, bound or background · REJECTED considered and not used
