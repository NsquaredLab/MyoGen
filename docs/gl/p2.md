
### Internal organization

Create a lightweight runtime package beneath the existing basic EMG package, with separate modules for:

- Execution policy and reporting.
- Memory measurement and admission control.
- Immutable numerical snapshots.
- Signal assembly.
- Cache storage.

The basic simulator must not import anatomical geometry, Subject objects, FEM code, or the new forward-model implementation.

The existing anatomical memory helper provides useful design and test patterns. Do not import it directly: it currently forces a minimum batch of one, uses stage-oriented sizing, and accumulates results in a list. Those behaviors do not implement this plan’s host-memory contract.

### Immutable preparation

Before parallel work, capture owned numerical arrays and mark internal snapshots read-only.

Preserve the existing random realization and draw order:

- Repeated `simulate_muaps()` calls retain their current realization semantics.
- A cache lookup must not skip random draws that the existing method performs.
- Worker count, batch size, and retries must not affect generated parameters or subsequent RNG state.
- Retry only from already-realized inputs.

Use actual array contents and relevant metadata for cache identity. Object identity and shape alone are insufficient.

### Shared signal assembly

Create one internal assembly engine, with modality adapters preserving:

- iEMG normalization.
- sEMG absolute amplitude.
- Existing template padding.
- Native and output sampling conventions.
- Electrode ordering and grid layout.

Implementation:

1. Preserve existing boolean spike-bin occupancy.
2. Prepare resampled templates once per compatible template/rate combination.
3. Accumulate contributions without storing one full recording per MU.
4. Support direct and blocked FFT convolution.
5. Use SciPy’s method estimate to choose direct or FFT computation.
6. Choose FFT block sizes within the controller’s allowance.
7. Reuse compatible template transforms.

Preserve NumPy’s current `mode="same"` semantics explicitly:

```text
full-convolution crop start = (min(T, K) - 1) // 2
output length              = max(T, K)
```

Here, `T` is the recording length and `K` the template length. Test templates longer than recordings; another library’s “same” mode may return a different length.

Retain overlap contributions across FFT blocks and perform final resampling with the existing time-grid convention.

### Cache dependencies

| Prepared object | Dependencies |
|---|---|
| Conductor preparation | Geometry, conductivities, formulation, numerical grids |
| Electrode preparation | Locations, dimensions, differentiation/filter settings, grids |
| MUAP templates | Realized fibres, sources, delays, electrodes, numerical settings |
| Resampled templates | Template contents, native/target rates, interpolation rules |
| FFT kernels | Resampled templates, transform length, dtype |

Changing spike trains preserves compatible template preparation. Changing electrodes invalidates affected responses and MUAPs while retaining an independent conductor preparation.

Mutable custom objects without a complete dependency representation are not eligible for persistent caching.

### Persistent cache

Add after in-memory execution passes acceptance tests.

- Disabled by default.
- Enabled through `cache_dir`.
- Use versioned JSON metadata and numerical array files; no pickle.
- Include input fingerprints, formulation identity, implementation version, and checksums.
- Commit entries atomically at completed-MU boundaries.
- Never publish incomplete or failed entries.
- Default dedicated-cache limit: 4 GiB.
- Eviction touches only recognized files owned by that cache.

A restarted calculation reuses entries only after regenerating or restoring the same explicitly identified realization. A seed alone is not sufficient cache identity.
