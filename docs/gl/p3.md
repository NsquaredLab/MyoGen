
### Current opportunity

The existing high-level iEMG path computes full time × contact × fibre SFAP arrays and then sums them into MUAPs.

The optimized high-level path needs only the current fibre batch and accumulated MUAP.

### Implementation

For each MU:

1. Establish the full MU’s original time grid, padding, delays, and other shared quantities.
2. Estimate required accumulator and batch storage.
3. Obtain the controller’s initial allowance.
4. Evaluate a bounded batch of the original fibres.
5. Apply the existing integer and fractional propagation shifts.
6. Commit the batch contribution to the MUAP accumulator.
7. Release temporaries and respond to memory-pressure requests.
8. Continue until all configured fibres are processed.
9. Apply existing electrode processing at its original stage.

Working SFAP storage becomes approximately:

```text
time × contacts × batch fibres
+ time × contacts accumulator
```

instead of:

```text
time × contacts × all fibres
```

Preserve per-fibre spatial quadrature and the complete MU’s time grid. Batch size must not change waveform duration or delay conventions.

### Compatibility

- Direct `MotorUnitSim.calc_sfaps()` calls retain their full-SFAP output.
- Existing diagnostic workflows remain available.
- Optimize the existing high-level zero-jitter calculation first.
- Preserve MU identities, selected-MU behavior, and placeholders.
- Keep normalization and output units unchanged.
- Preserve higher-precision intermediates where the existing calculation uses them.

Start by streaming the existing fibre calculation. Introduce additional vectorization only if profiling demonstrates a benefit within the same memory and equivalence limits.

### Required tests

- One fibre and many fibres.
- Unequal fibre lengths and conduction velocities.
- Integer and fractional propagation delays.
- Different electrode configurations.
- Batch sizes of one, several fibres, and the full small test population.
- Memory pressure midway through an MU.
- Allocation failure before batch commit.
- Repeatability across worker counts and retries.
- Agreement before normalization and after final electrode processing.
