
### Scientific boundary

Target the existing public frequency-domain sEMG formulation.

Preserve source equations, conductor boundaries, grids, electrode filtering, symmetry reconstruction, and resampling. Leave `use_unified=True` on the existing execution route in this release.

Do not merge development-branch scientific changes into the public model merely to obtain a faster implementation.

### Prepare invariant work

Move invariant calculations into immutable preparations:

- Frequency grids and mesh arrays.
- Grid-dependent source-kernel quantities.
- Conductor matrices and boundary terms.
- Electrode size and differentiation responses.
- Reusable position-dependent factors.

Share preparations across compatible fibres and MUs. Keep radial source position, fibre endpoints, innervation-zone effects, and angular offsets separate.

### Reuse the conductor’s output response

The current code repeatedly solves:

\[
A x=b
\]

and then uses a selected sum of components of \(x\).

Represent the required output as:

\[
h=c^Tx.
\]

Prepare once for each compatible matrix:

\[
A^Tw=c,
\]

then calculate each fibre’s response as:

\[
h=w^Tb.
\]

This avoids repeatedly solving the same matrix without forming an explicit inverse.

Implement separate selectors for the existing seven-variable and reduced five-variable bone-free systems. Preserve the public source-vector construction and subsequent processing.

Validate the preparation’s finite values and solve residual. Compare complete resulting waveforms with the reference, including poorly conditioned cases.

### Bounded evaluation

After the prepared-response route passes numerical tests:

1. Evaluate source vectors in bounded fibre batches.
2. Accumulate contributions in stable fibre order.
3. Reuse compatible conductor preparation across MUs.
4. Govern retained preparations and batch arrays through the memory controller.
5. Retain the existing downsampling stage after MU accumulation.

The first optimized surface release supports built-in electrode definitions and matching grid dimensions across multiple arrays. Validate this restriction upfront.

Unsupported custom electrodes and experimental formulations require explicit use of the existing route; do not silently switch scientific formulations.

### Failure and release behavior

Do not cache zero-filled failure results as successful MUAPs.

If the prepared-response optimization fails parity or performance acceptance, exclude it from the release. Shared signal assembly and adaptive-memory improvements can still ship for supported paths independently.
